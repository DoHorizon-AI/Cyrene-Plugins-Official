# Cyrene Memory Provider Contracts

The Plugins-owned Python projection of `memory.provider.v1`. It provides
immutable contract values and a dependency-free protobuf codec for the seven
direct invocation methods. It does not make network calls or define Product
authorization policy.

本 package 是 Plugins 所有的 `memory.provider.v1` Python 投影，提供不可变契约值和
七个直连调用方法的零依赖 protobuf 编解码器。它不发起网络调用，也不定义 Product 授权策略。
