# Model Provider SDK Source

| File | Responsibility |
|---|---|
| `_wire.py` | Dependency-free protobuf wire helpers. |
| `chat.py` | Text and structured chat contract values and codecs. |
| `embeddings.py` | Embedding contract values and codecs. |
| `__init__.py` | Public SDK exports. |

The `.proto` files under `contracts/proto/cyrene/model/provider/v1` remain the
schema authority.

| 文件 | 职责 |
|---|---|
| `_wire.py` | 零依赖 protobuf wire 辅助函数。 |
| `chat.py` | 文本及结构化 chat 契约值和编解码器。 |
| `embeddings.py` | Embedding 契约值和编解码器。 |
| `__init__.py` | SDK 公共导出。 |

规范以 `contracts/proto/cyrene/model/provider/v1` 下的 proto 为准。
