# Cyrene Knowledge Graph Contracts

The Python projection of `knowledge.graph.v1`. It provides generated protobuf
messages, method/type URL identifiers, and method-aware request/response
codecs. It stores graph facts and source references; Product authorization,
inference, and workflow policy remain with the host.

本 package 是 `knowledge.graph.v1` 的 Python 投影，提供生成的 protobuf 消息、方法/type URL
标识符和按方法区分的请求/响应编解码。它保存图数据及来源引用；Product 授权、推断和工作流策略由宿主持有。
