# Speech Provider SDK Source

| File | Responsibility |
|---|---|
| `codec.py` | Method identifiers, type URLs, and request/response validation. |
| `_generated/speech_provider_pb2.py` | Generated messages from the canonical speech proto. |
| `py.typed` | Marks the package as typed. |

Cancellation is carried by the Direct Plugin Runtime transport context.
