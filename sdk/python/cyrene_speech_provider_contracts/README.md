# Cyrene Speech Provider Contracts

The Python projection of `speech.provider.v1`, with generated protobuf
messages and method-aware request/response codecs. Inputs are bytes or an
opaque controlled artifact reference; arbitrary URLs and host paths are not
part of the contract. Runtime cancellation is carried by Direct Plugin Runtime.

本 package 是 `speech.provider.v1` 的 Python 投影，提供生成消息及按方法区分的请求/响应编解码。
输入为媒体 bytes 或受控的不透明制品引用；契约不包含任意 URL 或宿主路径。运行时取消由 Direct Plugin Runtime 传递。
