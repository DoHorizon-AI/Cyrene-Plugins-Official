# Cyrene Tool Provider Contracts

The Python SDK for the Plugins-owned `tool.provider.v1` payloads. It exposes
generated protobuf message classes and the canonical Direct Plugin method and
type URL constants. Tool policy, authorization, and invocation routing remain
with the Product host.

本 SDK 提供 Plugins 所有的 `tool.provider.v1` Python 负载，导出生成的 protobuf 消息类、
Direct Plugin 方法名和规范 type URL。工具策略、授权和调用路由仍由 Product 宿主持有。
