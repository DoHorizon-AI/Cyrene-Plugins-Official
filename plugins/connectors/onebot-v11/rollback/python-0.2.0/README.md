# OneBot v11 Python 0.2.0 rollback artifact

This package is retained as the rollback artifact for the `0.2.0` Python
runtime. The formal `0.3.0` package uses the C# Native AOT executable and does
not run this payload or provide a dual-runtime compatibility mode.

本包是 `0.2.0` Python runtime 的独立回滚制品。正式 `0.3.0` 包使用 C# Native AOT
可执行文件，不会启动本包，也不提供双运行时兼容模式。
