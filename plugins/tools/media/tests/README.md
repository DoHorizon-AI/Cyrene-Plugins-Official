# Media Library Tests / 媒体目录测试

The suite generates image fixtures locally and verifies exact content digests,
duplicate handling, soft-delete recovery, tamper detection, cursor pagination,
and PNG card output. It does not use external services or production state.
测试在本地生成图片夹具，验证哈希、去重、恢复、防篡改、分页和 PNG 卡片输出。
