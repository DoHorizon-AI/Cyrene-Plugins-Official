# Generated Runtime Bindings

This directory contains the generated `tool.provider.v1` Protocol Buffers
binding used by the DirectPluginRuntime adapter. Regenerate it from the
canonical Plugins proto when the runtime contract changes.

此目录包含 DirectPluginRuntime adapter 使用的 `tool.provider.v1` Protocol Buffers 生成绑定。
运行时契约变化时，应从 Plugins 权威 proto 重新生成。
