# Generated provider protocol

This directory contains the `tool.provider.v1` protobuf binding used by the
DirectPluginRuntime entrypoint. Keep generated protocol code separate from the
provider implementation.

## Files

| File | Responsibility |
| --- | --- |
| `tool_provider_pb2.py` | Generated `tool.provider.v1` request and response messages. |
| `__init__.py` | Marks the generated binding package. |

Read the binding only when changing the canonical provider wire protocol.
