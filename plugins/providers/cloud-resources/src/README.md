# Source tree

This directory contains the importable Python package for the cloud resource
observation Plugin.

| Path | Responsibility |
| --- | --- |
| `cloud_resources_provider/` | Settings, fixed vendor adapters, typed tool dispatch, and package tests. |

Read the package README first, then `settings.py`, `cloud_api.py`, and `plugin.py`.

## 源码目录

此目录包含云资源观察 Plugin 的可导入 Python 包。

| 路径 | 职责 |
| --- | --- |
| `cloud_resources_provider/` | 激活设置、固定供应商适配器、类型化工具分发和包测试。 |

建议先阅读包 README，再按 `settings.py`、`cloud_api.py`、`plugin.py` 的顺序阅读。
